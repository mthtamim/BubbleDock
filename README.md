# BubbleDock v1.2.0

BubbleDock হলো Tamim-এর নিজের ফোনের জন্য বানানো ভাসমান বাবল অ্যাপ।
সাধারণত শুধু বাবল সার্কেল দেখা যাবে। বাবলে ডাবল ট্যাপ করলে নিচে
এক লাইনে বড় অ্যাপের ডক আসবে, সেখান থেকে যেকোনো অ্যাপে যাওয়া যাবে।
বাবলে একবার ট্যাপ করলে ঐচ্ছিক অ্যাকশন আর গ্রুপ আসবে।

## v1.2.0-তে যা আছে

- ভাসমান বাবল: ড্র্যাগ করে সরানো, এজে স্ন্যাপ, অলস থাকলে হালকা স্বচ্ছ,
  নিচের ট্র্যাশ জোনে টেনে সাময়িক লুকানো, নোটিফিকেশন থেকে বন্ধ করা
- আইকন-অনলি ওভারলে (v1.2): বাবল, ডক, অ্যাকশন — কোথাও লেখা নেই, শুধু
  আইকন। ডক এক লাইনে, বড় আইকন, 🔍 আর ✕ আইকন; সার্চ বাক্সে হিন্ট নেই
- এক ট্যাপে ঐচ্ছিক অ্যাকশন: শুধু আইকন — কুইক অ্যাকশন আর গ্রুপের আইকন
- প্রোফাইল, পার-অ্যাপ বাবল লুকানো, বাবল সাইজ, JSON ব্যাকআপ কপি
- সেটিংস (v1.2, PhoneLink স্টাইল): কালো সবুজ ব্যাকগ্রাউন্ড, emerald
  আউটলাইনের ডার্ক কার্ড; লেখা খুব কম, কোনো ব্যাখ্যা নেই
- সব সেটিংস শুধু ফোনেই থাকে। কোনো INTERNET পারমিশন নেই, কোনো সার্ভার নেই।

## পারমিশন, সত্যি করে

- Overlay: বাবল দেখাতে। ছাড়া বাবল চলবে না।
- Usage Access: রিসেন্ট অ্যাপ দেখাতে। ছাড়া বাকি সব চলবে।
- ব্যাটারি অপটিমাইজেশন ছাড়: XOS যাতে বাবল মেরে না ফেলে।
- Accessibility (ঐচ্ছিক): শুধু ব্যবহারকারীর ট্যাপে ব্যাক, রিসেন্ট,
  স্ক্রিনশট করার জন্য। স্ক্রিনের কনটেন্ট পড়ে না, কোনো জেসচার করে না,
  অন্য অ্যাপের ইভেন্টে সাড়া দেয় না।
- Device Admin (ঐচ্ছিক): শুধু ব্যবহারকারীর ট্যাপে স্ক্রিন লক করার জন্য।
- Android 10+ এ WiFi সরাসরি টগল করা যায় না, তাই WiFi অ্যাকশনটি
  সিস্টেমের WiFi প্যানেল খোলে — টগল হয়েছে বলে মিথ্যা দাবি করে না।

## বিল্ড

GitHub Actions-এ `build-apk.yml` দিয়ে debug APK বানানো হয়, তারপর
v1.1.0 রিলিজে APK দেওয়া হয়। লোকালে Kotlin কম্পাইল আর AAPT
যাচাই হয় না — সেটা CI-তেই প্রমাণ হবে, এটা VALIDATION.md-তে লেখা আছে।
সতর্কতা: GitHub App-এর Workflows পারমিশন নেই, তাই workflow ফাইল
পুশ করা যাবে না — workflow বদলাতে হলে ব্রাউজারে পার্সোনাল অ্যাকাউন্ট
দিয়ে আগে আপডেট করতে হবে, তারপর কোড পুশ করতে হবে।
